👋 Hey! I'm **Gloire**, a software engineer building native tools for macOS and iOS. Creator of [cocker](https://github.com/gloiiire/cocker), a Docker-compatible container engine for Apple Silicon built on Virtualization.framework, and of [pinkha](https://github.com/pinkha-app/pinkha), a note-taking app in Rust + SwiftUI. I also lead [ONT Bible](https://github.com/ONTBible), a French translation of the Hebrew biblical texts and the apps that read it.
